## Deploy (one-time, from zip on Mac/PC)

```
unzip SGOS_Mobile_Package.zip
cd SGOS_Mobile_Package
cp .env.example .env
npm install
npm run db:push
npm run start
```

Set in `.env`:
```
DATABASE_URL=your-supabase-postgres-url
SGOS_OPERATOR_PHONE=+1YOURNUMBER
SENDBLUE_API_KEY=your_key
SENDBLUE_API_SECRET=your_secret
SENDBLUE_FROM_NUMBER=+1YOURNUMBER
SGOS_MOCK_SMS=false
```

Open on phone: `https://your-host/sgos`
